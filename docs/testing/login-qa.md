# 로그인 시험 시나리오

`docs/phases/phase-22-account-login.md`(이하 지시서)의 흐름·화면·설계를 줄 단위 시험으로 풀어 쓴 표다. 병합 전(qa ①)에 쓰고, 병합 뒤(qa ②) 코드와 대조한다. 기대 결과는 지시서 문구를 그대로 옮겼다. 문서 안 모순·빈틈은 시나리오와 섞지 않고 맨 끝 「문서 모순·빈틈」에 모았다.

## 읽는 법

**확인 수단** 열 약호:

| 약호 | 뜻 | 담당 지표 |
|---|---|---|
| 시험 | Deno 시험(통신 없는 순수 로직·서버 판정) | 서버 S3~S8, 앱 F3 |
| 흉내 | 개발용 결과 흉내(`accountSimulation.ts`, 설정 `__DEV__` 영역)로 화면·분기를 띄워 봄 | D2 |
| 실기기 | 사람이 iPhone에서 확인(Step 8) | 이 문서 「실기기에서만 확인」 |

- 수단 열은 qa ②(병합 뒤, `65adaab`)에서 실제 시험·흉내 선택·실기기로 채웠다. 시험은 `파일약호:줄`(그 줄의 `Deno.test` 이름 — 목록은 끝의 「qa ② 결과 > 시험 약호」), 흉내는 `` `함수=결과` ``(설정 `__DEV__`「계정 결과 흉내」) 또는 「버튼 이름」(「계정 화면 열기」), 실기기는 `R-nn`(「실기기에서만 확인」). "시험 없음"은 그 행을 자동 시험이 덮지 않는다는 뜻이다.
- 근거 열은 지시서 절 이름이다. 「흐름 1」은 지시서 '흐름 > 1. 홈 화면 진입'.
- 번호: H1~H6 = 흐름 1~6, L = 로그인 결과, W = 창 A~D, M = 합치기, D = 계정 삭제, N = 닉네임, O = 로그아웃·삭제 뒤 기기 정리, U = 1.1.0·OTA 사용자, G = 위시 흔적 없는 거절, B = 반시트, S = 설정 계정 영역, X = 목록 실패.
- 상태 약어: 세션 없음 = 기기에 세션 저장값 없음. "서버 거절" 등 기기 상태는 설계 4 `accountState` 값.
