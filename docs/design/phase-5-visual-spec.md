# Phase 5 비주얼 명세 (목업 리스킨)

> **색 토큰 정본 = [`color_tokens.md`](./color_tokens.md)** (같은 폴더). 이 문서는 그 토큰을 **`theme.ts`에 어떻게 매핑할지** + **화면별 리스킨 지시**만 담는다. 색 값의 단일 출처는 정본 파일이다(중복 정의 금지).
>
> 화면 정본 = `docs/design/`의 스크린샷 `M1_home.png` · `M2_folder.png` · `M3_addWish.png` · `M6_itemDetail.png` · `M7_itemInformation.png`(라이트). 원본 목업 `Wish-Shot-mockup.html`은 자기압축이라 스크린샷을 정본으로 삼는다.
>
>
> **Phase 24 갱신(2026-11-10)**: 탭 순서·기본 탭·알림 탭·탭바 배지·새 링크 점·등록/편집 폼 순서·스낵바·공유 확인창의 **현재 상태는 맨 아래 '화면 명세 — Phase 24' 절**이다. 앞 절의 Phase 5 서술과 다르면 그 절을 따른다(앞 절은 Phase 5 기록으로 남겨 두고 바뀐 곳에 표시만 했다).
>
> **번역 원칙**: 목업은 HTML/CSS, RN은 캐스케이드·CSS grid 없음·flex 기본값 다름. **값(색·간격·radius·폰트)만 토큰으로 옮기고 레이아웃은 RN(FlatList/flex)로 재구현.** 목업의 "or browse files / 회색 타일 / 점선 테두리"는 **이미지 슬롯 플레이스홀더**이지 실제 UI가 아니다(실제 앱은 signed URL 썸네일 또는 빈 `placeholder` 타일).

## ⚠️ 배경은 흰색이다

목업 캔버스의 웜 그레이지(`#ECEAE5`)는 **디자인 툴 캔버스 색**이지 앱 배경이 아니다. 실제 앱 배경은 정본 토큰 `background` = **`#FFFFFF`(Light) / `#000000`(Dark)**. 스크린샷 모두 흰 배경.

## ⚠️ wine 사용 규칙 (정본 규칙 1·2)

`wine`은 **하트(찜)·찜 카운트·New 점·탭바 배지·앱 아이콘** 에만. 삭제·에러는 항상 `destructive`. → 그 자리는 **전부 Phase 6**(찜·New·탭바 배지). **Phase 5 화면색은 흑/백/회색 모노톤**, 와인은 토큰만 준비.
- **Phase 24부터 실제로 쓰는 자리**: **새 링크 점**(저장 뒤 링크가 붙고 아직 안 본 위시 — 타일·알림 목록 썸네일 좌상단)과 **알림 탭 배지**(안 읽은 알림 수). 정본의 'New 점'·'탭바 배지' 자리를 이 용도로 먼저 쓴다(새로 담긴 위시의 New 점은 하지 않음). 찜 하트·찜 카운트는 아직 없다.

## 화면 명세 — Phase 24 (탭·폼·알림, 2026-11-10 현재 상태)

> 작업 기록·결정 이유: `docs/phases/phase-24-ux-improvements.md`. 값은 모두 `theme.ts` 토큰(원시 hex 금지). 앱은 **라이트 전용**이다 — 다크 토큰(`colorsDark`)은 상세 뷰어와 스낵바(어두운 바)만 쓴다.

### 하단 탭바 (`CustomTabBar`)
- **카테고리 · 전체 · 알림 · 검색** 4탭(아이콘 `square.grid.2x2.fill` · `square.stack` · `bell` · `magnifyingglass`). **앱을 열면 전체**(`/` = 전체 탭).
- 탭 좌우 여백 16pt(`spacing.three`) — 알약 폭 약 260pt로 320pt(확대 보기)에도 들어간다. 라벨 11pt, 글자 확대는 1.3배까지.
- **알림 배지**: 아이콘 우상단(top -4, right -10) `wine`(`accent`) 원 — 최소 폭 16pt·높이 16pt·좌우 4pt, 흰(`bg`) 11pt 굵게 숫자(안 읽은 알림 수, 최대 20). 접근성 라벨 "알림, 읽지 않은 알림 N개".

### 전체 탭 (기본 탭)
- 헤더 우측에 설정 톱니(카테고리 탭과 같은 자리·모양).

### 등록·편집 폼 (M3 개정)
- **카드 순서**: 카드 1 = 제품명 *·브랜드·가격 → (AI 카테고리 추천 안내) → 카드 2 = 카테고리 ›·링크 → (링크 안내 — 등록만) → 카드 3 = 메모 → 태그. 편집 화면도 같은 순서.
- **'AI가 채움' 칩 없음**. 상태 문구("AI가 채웠습니다. 확인하세요." 등)와 추천 안내는 유지.
- **한 줄 입력**(`FormLineInput` — 제품명·브랜드·가격·링크): 값이 들어가면 우측 정렬. 넘치면(입력 중 아님) 앞부분부터 좌측 정렬 한 줄 + 오른쪽 끝 28pt 페이드(`bgCardClear` → `bgCard`). 입력하지 않고도 **옆으로 밀어** 잘린 부분을 보고(민 만큼 왼쪽 끝도 페이드, 끝까지 밀면 오른쪽 페이드 사라짐), 탭하면 입력. 입력 중에는 기본 입력(페이드 없음).
- **링크 칸 자리표시**: 등록 — 찾는 중 스피너 + "링크 찾는 중…", 못 찾음 "링크를 직접 입력하세요", 그 밖 `https://`. 편집 — 빈 칸이면 늘 "링크를 직접 입력하세요".
- **링크 안내(등록만)**: 카드 2 바로 아래 **오른쪽 정렬로 늘 보임** — "저장 후에도 링크를 계속 찾습니다. 앱을 닫으면 중단됩니다." 13pt `labelSecondary`(`textSub`).

### 타일 — 링크 찾기 상태 (`PhotoTile`, 전체·카테고리·태그·검색 그리드)
- **찾는 중**(저장 뒤 이어 찾기): 썸네일 불투명도 0.5(200ms 페이드, 모션 줄이기면 바로). 점 없음.
- **새 링크**(붙었고 아직 안 봄): 좌상단(top 6·left 6) **새 링크 점** `NewDot` — `wine` 8pt + 흰(`bg`) 0.5pt 테두리 + 그림자 `shadow.onPhoto`(`boxShadow` 검정 20%·y 1pt·blur 2pt·스프레드 1pt — 정본 규칙 4 '사진 위 표시'). 상세에서 그 위시를 보면 사라짐.
- **못 찾음·평소**: 표시 없음. 흐림과 점은 동시에 나오지 않는다.

### 알림 탭 (M8 신규 — `(tabs)/notifications.tsx`)
- Large Title "알림". 기기 안 기록(최근 20개·14일).
- **행**: 썸네일 48pt(모서리 `radius.sm`) · 한 줄 "**{제품명}**에 링크를 붙였습니다"(15pt — 제품명 700, 길면 제품명만 말줄임) · 상대 시각(13pt — 방금 / N분 전 / N시간 전 / 어제 / N일 전). 구분선은 썸네일 오른쪽부터.
- **안 읽음**: 썸네일 좌상단(top 3·left 3) 새 링크 점 + 검정(`label`) 글씨. **읽음**: 썸네일 불투명도 0.45, 문장 `labelSecondary`, 시각 `inactive`(`textDisabled`).
- 누르면 위시 상세. 비었을 때: "알림 없음" / "저장한 위시에 링크를 붙이면 여기에 표시됩니다."

### 스낵바 (`SnackbarHost` — 앱 전체 1개)
- 탭바 바로 위(하단 안전 영역 또는 8pt 중 큰 값 + 72pt), 좌우 16pt, 모서리 `radius.lg`, 어두운 바(`colorsDark.bgCard`) + `shadow.floating`.
- 한 줄 "**{제품명}**에 링크를 붙였습니다"(흰 15pt — 제품명 700·말줄임) + 오른쪽 **보기**(흰 15pt 700 → 위시 상세).
- 3초(VoiceOver 켜면 6초) 뒤 사라짐, 여러 개면 차례로. 나타남·사라짐 180ms 페이드 + 16pt 미끄러짐(모션 줄이기면 없음). 네이티브 모달(등록·편집·상세·정보 시트) 위에도 보인다(`FullWindowOverlay`), 스낵바 밖 터치는 아래 화면으로.

### 작성 중 새 공유 확인창 (`ShareConfirmDialog`)
- iOS 확인창 모양: 딤(`overlay`) 위 가운데 270pt 카드, 모서리 `radius.lg`, 흰 바탕.
- 제목(17pt 600, 가운데) "새 사진을 받았습니다" / "새 링크를 받았습니다"(묻는 중 또 받으면 마지막 것으로 바뀜), 본문(13pt) "지금 열면 작성 중인 내용은 저장되지 않습니다."
- 버튼 두 개(헤어라인 구분, 높이 44pt 이상): **저장 후 열기**(보통) · **지금 열기**(600). 바깥을 눌러도 닫히지 않는다.
