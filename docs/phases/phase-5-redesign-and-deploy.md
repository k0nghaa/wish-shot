## 목표 (Goal)

Phase 4까지 등록·OCR 자동채움·편집·카테고리 이동·태그·설정이 완성됐다. Phase 5는 **현재 화면들을 목업의 룩앤필로 리스킨**하고, **일부 구조(하단 탭바·상세 뷰어/정보 시트)** 를 도입하며, **첫 외부 배포(TestFlight)**를 한다. 이 Phase가 끝나면: 앱이 흰 배경 + iOS 시스템 그레이 **모노톤**의 담백한 사진앱 톤으로 바뀌고(와인은 찜 전용이라 Phase 6에 등장), **하단 알약 탭바(전체/폴더/검색)** 로 오가고(검색은 플레이스홀더), 저장 이미지를 **원본 비율 풀스크린으로** 보며 **정보(i) 하프시트**로 메타정보를 보고, **로그인 없이 켜면 바로 쓰고**(익명), 남이 **TestFlight로 받아** 연다.

**이 Phase의 핵심 검증**: (1) 새 팔레트가 전 화면에 일관 적용(옛 브랜드색 잔재 없음). (2) 홈·상세·등록이 목업 톤으로 리스킨. (3) **하단 알약 탭바 동작**(전체=전체 그리드, 폴더=홈, 검색=플레이스홀더). (4) 상세 풀스크린 뷰어(원본 비율) + **정보(i) 하프시트**. (5) 새 설치에서 로그인 화면 없이 홈 진입·등록·조회 정상(RLS). (6) TestFlight 내부 테스터 설치·익명 즉시 사용. (7) 발표는 내 폰 dev client 라이브로 완주.

## 포함되는 구조 변경 (리스킨을 넘는 부분 — 주의)

순수 리스킨을 넘어 아래가 이번에 들어온다. **시간 압박이 커지는 지점이므로 리스킨을 먼저 끝내고 붙인다.**
- **하단 알약 탭바(전체/폴더/검색)** — `_layout`을 Tabs 구조로. 커스텀 플로팅 알약 `tabBar`(JS 전용). **검색 탭 = "검색 기능 추가 예정" 플레이스홀더만.** **전체 탭 = 전체 아이템 그리드**(찜 필터·New 배지 제외).
- **상세(M6) 뷰어 재구성 + 정보(i) 하프시트(M7)** — 상세 상세정보를 `Modal` 기반 하프시트(네이티브 라이브러리 없이)로 이동. 하단 액션바 = 정보·링크·편집·삭제.

## 이 Phase에서 하지 않는 것 (→ Phase 6)

- **찜(하트)** · **New 점** · **탭바 New 배지**(← 여기서 wine 등장) — DB 마이그레이션·상태 추적 필요.
- **검색 기능 로직**(탭·플레이스홀더 화면은 포함, 실제 검색은 제외) · **빠른 담기 팝업(M4)** · **폴더 내 필름스트립** · **상세 공유 액션** · **전체 탭 찜 필터 칩**.
- **출처 앱 표시**("인스타그램에서 공유") — 현재 미저장 데이터.
- **다크 모드 실적용·검증**(토큰만 준비) · 이메일 가입/계정 승격/정리 · 이미지 자르기 · URL 공유 · Apple 로그인 · Android.
- **용어 "카테고리 → 폴더" 전면 교체**는 미결(아래) — 확정 전엔 현행 유지.

**여유 시(stretch, 시간 남으면):** 당겨서 새로고침 · 로딩 스켈레톤. (핵심은 화면 리스킨 — 이 둘은 후순위.)

## 제약 (Constraints) — 에이전트가 지킬 것

Phase 1~4 규칙(한국어 문자열, 디자인 토큰, 비밀값 커밋 금지, 커밋 컨벤션, 문서 동기화, 데이터 레이어 경유, 모르면 묻기, 버전 임의 인상 금지)을 그대로 승계하고 다음을 추가한다. **단, 카피 톤 규칙(CLAUDE.md 규칙 4)은 이번에 "간결 단답형"으로 개정됨** — 아래 제약 8 참조.

1. **네이티브 라이브러리는 보편적인 것이면 허용 — 단 트레이드오프를 제시하고 사람 승인 후 추가한다.** 판단 기준은 **재빌드 여부**: (a) **이미 설치된 네이티브**(`react-native-reanimated`·`react-native-gesture-handler`·`react-native-screens`·`@expo/ui`·`expo-glass-effect`·`expo-symbols`)나 **그 위의 순수 JS 라이브러리**(예: `@gorhom/bottom-sheet`)는 **재빌드 불필요 → 현재 dev client에서 즉시 확인, 자유롭게 사용**. (b) **새 네이티브 모듈**(예: `expo-haptics`)은 **재빌드 필요** → 데모 전 dev client를 한 번 재빌드해야 하고 TestFlight 빌드에 포함. 새 네이티브 모듈은 **모아서** 추가하고 임의로 늘리지 않는다.
2. **원시 hex 직접 사용 금지.** 색은 `src/constants/theme.ts` 시맨틱 토큰 경유. 팔레트 교체는 **토큰 값만** 바꾸고 **이름은 유지**해 전 화면 자동 전파.
3. **다크 토큰은 준비만, 소비하지 않는다.** Light 값으로 완성, Dark 값(`#A83A4E` 등)은 별도 맵에 두되 스위칭은 Phase 6.
4. **구조 변경은 위 "포함되는 구조 변경" 두 가지로 한정.** 하단 탭바(전체/폴더/검색)와 정보 하프시트(M7)만 추가한다. 그 외 새 라우트·화면(M4 빠른 담기, 필름스트립 등)은 만들지 않는다.
5. **데이터·RLS·정규화·Storage 규칙 불변.** 스키마 변경 없음(찜·New는 Phase 6). 익명 로그인은 `auth` 쿼리 + `_layout` 부트스트랩만.
6. **이미지 원본은 온전 — 표시만 고친다.** picker는 `quality:1`·크롭 없음. 짤림은 `contentFit:"cover"` 표시 크롭일 뿐. 풀스크린 뷰어는 `contentFit:"contain"`+원본 비율. 업로드/파이프라인 불변.
7. **문서를 현실에 맞춘다.** 구현 후 `CLAUDE.md`·`README.md` 갱신 + 이 문서 "결과 기록" 작성.
8. **사용자 노출 카피를 간결 단답형으로 통일(iOS 기본 앱 톤).** 리스킨하며 각 화면 문자열에서 대화체("~예요/~해요")를 제거하고 CLAUDE.md 규칙 4 기준(라벨·버튼=명사/동사 단답, 안내·에러="~습니다" 또는 명사구)으로 정리한다. 에러·플레이스홀더·접근성 라벨 포함. 이 정리는 화면별 리스킨(Step 2~5)에 포함한다.
