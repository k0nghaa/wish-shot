위시샷(WishShot) 개인정보처리방침

시행일: 2026년 9월 16일

위시샷(이하 “앱”)은 스크린샷으로 저장한 관심 제품을 개인 위시리스트로 관리하는 iOS 앱입니다. 본 방침은 앱이 어떤 정보를 어떻게 처리하는지 설명합니다.

1. 수집·저장하는 정보

  • 사용자가 저장한 위시 정보: 제품명, 브랜드, 가격, 링크, 메모, 태그, 카테고리(폴더).
  • 이미지: 사용자가 담은 스크린샷/사진. 사용자 본인만 접근 가능한 비공개 저장소에 저장됩니다.
  • 익명 식별자: 로그인 없이 기기별로 데이터를 구분하기 위한 익명 계정 식별자. 이름·이메일 등 개인 식별 정보는 수집하지 않습니다.

2. 이미지 처리 방식

  • 이미지의 문자 인식(OCR)은 기기 내에서 수행되며, 이미지 자체는 인식 목적으로 외부에 전송되지 않습니다.
  • AI 정제(제품명·브랜드·가격 자동 채움)에는 인식된 텍스트만 전송됩니다. 다만 텍스트를 찾지 못한 경우, 사용자가 직접 선택한 제품 영역 이미지만 확인 후 전송되며, 원본 전체·그 외 부분은 전송되지 않습니다. 전송된 영역 이미지는 정제 목적으로만 사용되며 저장하지 않습니다.
  • 저장된 이미지는 사용자 본인만 접근할 수 있는 비공개 저장소에 보관됩니다.

3. 제3자 처리(수탁)

  • Supabase: 데이터 저장, 이미지 비공개 저장소, 익명 인증에 사용됩니다.
  • Anthropic(Claude): 인식된 텍스트를 정제해 제품 정보를 자동 채우는 데 사용됩니다. 텍스트를 찾지 못한 경우에 한해, 사용자가 선택한 제품 영역 이미지만 확인 후 전송되며 저장하지 않습니다.

4. 인증

앱은 익명 로그인으로 동작합니다. 별도의 회원가입·이메일 없이 기기별 익명 세션으로 데이터를 보관하며, 개인 계정 정보를 수집하지 않습니다.

5. 보관 및 삭제

  • 저장한 위시·이미지는 사용자가 앱에서 삭제할 때 함께 삭제됩니다.
  • 앱 삭제 시 기기의 익명 세션은 초기화됩니다.
  • 데이터 삭제를 원하시면 아래 연락처로 요청하실 수 있습니다.

6. 아동의 개인정보

앱은 아동을 대상으로 하지 않으며, 개인 식별 정보를 수집하지 않습니다.
