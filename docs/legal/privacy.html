위시샷(WishShot) 개인정보처리방침

시행일: 2026년 9월 16일 | 개정: 2026년 12월 ○일(1.2.0 출시 전 게시일로 채움)

위시샷(이하 “앱”)은 스크린샷으로 저장한 관심 제품을 개인 위시리스트로 관리하는 iOS 앱입니다. 본 방침은 앱이 어떤 정보를 어떻게 처리하는지 설명합니다.

1. 수집·저장하는 정보

  • 사용자가 저장한 위시 정보: 제품명, 브랜드, 가격, 링크, 메모, 태그, 카테고리(폴더).
  • 이미지: 사용자가 담은 스크린샷/사진. 사용자 본인만 접근 가능한 비공개 저장소에 저장됩니다.
  • 계정 식별자: 데이터를 사용자별로 구분하기 위한 계정 식별자. 로그인 없이 시작하면 기기별 익명 계정 식별자이고, Apple·카카오로 로그인하면 그 계정의 식별자입니다.
  • 로그인 정보(Apple·카카오로 로그인한 경우): Apple·카카오가 제공하는 사용자 고유 번호, 이메일 주소(Apple에서 이메일 가리기를 고르면 Apple이 만든 중계 주소, 카카오는 필수 동의 항목), 닉네임. 이름은 받지 않습니다. 이메일은 계정 식별, 중복 가입 방지, 서비스 운영 관련 중요 안내에 씁니다.
  • 탈퇴 사유(선택): 계정을 삭제할 때 고른 사유와 ‘기타’에 직접 입력한 글(200자 이하). 계정 식별자 없이 저장합니다.
  • 분석 기록: 위시를 저장할 때, 그 위시의 AI 자동 채움에 쓴 인식된 텍스트와 AI 정제 결과, 분석 상태(성공·실패 등)와 시각. 저장하지 않은 분석은 기록하지 않습니다. AI 정확도 개선과 오류 분석에 사용합니다. 보관 기간은 아래 “7. 보관 및 삭제”를 참고하세요.
  • 요청 기록: AI 자동 채움·링크 찾기의 요청 한도를 지키기 위한 계정 식별자별 요청 횟수와, 실패한 요청의 계정 식별자·날짜·실패 사유(외부 서비스 응답 코드 등)·횟수. 요청 내용은 포함하지 않습니다.
  • 앱 사용 정보: 품질 개선을 위한 앱 사용 이벤트(기능 사용 여부, 동작 상태값, 소요 시간)와 기기 기본 정보(기기 모델, OS 버전, 앱 버전, 언어·시간대 설정). 자세한 내용은 아래 “4. 앱 사용 통계 및 국외 이전”을 참고하세요.
  • 오류·크래시 정보: 앱 안정성 개선을 위한 오류 종류, 발생 위치, 앱 실행 상태와 기기 정보. 자세한 내용은 아래 “5. 오류·크래시 수집 및 국외 이전”을 참고하세요.

2. 이미지 처리 방식

  • 이미지의 문자 인식(OCR)은 기기 내에서 수행되며, 이미지 자체는 인식 목적으로 외부에 전송되지 않습니다.
  • AI 정제(제품명·브랜드·가격 자동 채움)에는 인식된 텍스트만 전송됩니다. 다만 텍스트가 부족하거나 사용자가 ‘제품 영역으로 분석’을 누른 경우, 사용자가 직접 선택한 제품 영역 이미지만 ‘분석’을 누를 때 전송되며, 원본 전체·그 외 부분은 전송되지 않습니다. 전송된 영역 이미지는 정제 목적으로만 사용되며 저장하지 않습니다.
  • 저장된 이미지는 사용자 본인만 접근할 수 있는 비공개 저장소에 보관됩니다.

3. 제3자 처리(수탁)

  • Supabase: 데이터 저장, 이미지 비공개 저장소, 인증(익명·Apple·카카오 로그인)에 사용됩니다.
  • Anthropic(Claude): 인식된 텍스트를 정제해 제품 정보를 자동 채우는 데 사용됩니다. 텍스트가 부족하거나 사용자가 ‘제품 영역으로 분석’을 누른 경우에는 사용자가 선택한 제품 영역 이미지만 ‘분석’을 누를 때 전송되며 저장하지 않습니다. 또한 등록 화면에서 AI 분석으로 제품명이 채워지면(저장하기 전에도) 제품명·브랜드와 캡처에서 알아낸 판매처(사이트 주소 또는 쇼핑몰 이름)로 웹 검색을 해 판매처 링크를 찾는 데 사용됩니다. 링크 찾기에는 사진·인식된 텍스트 원문·메모·계정 식별자를 전송하지 않습니다.
  • Google(Web Risk): 링크를 넣기 전에 찾은 판매처 링크 주소와, 캡처에 주소가 보인 쇼핑몰의 검색 페이지 주소를 악성 사이트 목록과 대조하는 데 사용됩니다. 판매처의 검색 결과로 연결하는 링크는 주소에 검색어인 제품명(브랜드 포함 가능)이 들어갈 수 있습니다.

Apple·카카오 로그인은 사용자가 Apple·카카오 화면에서 직접 동의한 정보(고유 번호, 이메일)를 받아 계정을 만드는 데 씁니다. 계정을 삭제하면 서버가 Apple에는 삭제 때 다시 확인받은 인증 코드로 로그인 연결 철회를, 카카오에는 카카오 사용자 고유 번호로 연결 해제를 요청합니다. Apple·카카오의 로그인 토큰은 서버에 저장하지 않습니다.

링크 찾기에서 캡처에 주소가 보인 쇼핑몰은, 그 쇼핑몰에서 같은 상품을 찾기 위해 서버가 제품명만 그 쇼핑몰의 사이트 검색어로 보냅니다. 계정 식별자 등 다른 정보는 보내지 않습니다.

6. 인증

  • 로그인 없이 시작할 수 있습니다. 이때는 기기별 익명 계정으로 데이터를 보관하며, 앱을 삭제하거나 기기를 바꾸면 이전 데이터를 되찾을 수 없습니다.
  • 원하면 Apple 또는 카카오로 로그인할 수 있습니다. 같은 이메일은 하나의 계정이며, 한 계정에는 로그인 수단 하나만 쓸 수 있습니다.
  • 로그인하면 로그인 없이 담은 위시를 그 계정으로 옮깁니다. 같은 위시가 이미 계정에 있으면 계정의 위시를 남기고 비어 있는 항목만 채우며, 옮긴 뒤 익명 계정은 삭제합니다.
  • iPhone 설정에서 위시샷의 Apple 로그인 연결을 끊으면 앱에서 로그아웃되며, 데이터는 계정을 삭제하기 전까지 유지됩니다.

7. 보관 및 삭제

  • 저장한 위시·이미지는 사용자가 앱에서 삭제할 때 함께 삭제됩니다.
  • 위시를 삭제하면 그 위시의 분석 기록에서 인식된 텍스트와 AI 결과를 지우고, 분석 상태·실패 사유·시각만 통계용으로 남깁니다. 익명 계정이 삭제되면 분석 기록도 함께 삭제됩니다.
  • 계정 삭제: 설정 > 계정 삭제에서 언제든 계정을 삭제할 수 있으며 즉시 처리됩니다(로그인 없이 쓴 익명 계정도 삭제할 수 있습니다). 위시·이미지·분석 기록·닉네임·로그인 정보·이메일을 모두 지우고, 삭제 전에 Apple 로그인 연결 철회 또는 카카오 연결 해제를 요청합니다. 연결 해제에 실패하면 아무것도 지우지 않으며, 사용자가 ‘연결 해제 없이 삭제’를 고른 경우에만 계정을 지우고 Apple·카카오에서 직접 연결을 끊는 방법을 안내합니다.
  • 계정을 삭제해도 통계는 남습니다: 계정 식별자를 떼어 낸 요청 실패 기록의 날짜·사유별 합계, 계정 식별자 없이 저장한 탈퇴 사유의 날짜·사유별 횟수, 이미 수집된 앱 사용 이벤트(4절). 탈퇴 사유 중 ‘기타’에 직접 입력한 글은 3년 뒤 삭제합니다.
  • 요청 기록 중 실패 기록(계정 식별자·날짜·실패 사유·횟수)은 요청 한도 운영과 오류 분석을 위해 익명 계정이 자동 삭제된 뒤에도 보관될 수 있습니다. 요청 내용은 포함하지 않습니다.
  • 앱 삭제 시 기기의 세션은 초기화됩니다. 로그인한 계정은 다시 로그인하면 데이터를 볼 수 있고, 익명 계정의 데이터에는 다시 접근할 수 없습니다.
  • 저장한 위시가 없는 비활성 익명 계정(생성 후 30일 경과)은 주기적으로 자동 삭제됩니다. 삭제된 후에도 앱을 다시 열면 새 익명 세션으로 즉시 이용할 수 있습니다.
  • 어떤 위시도 참조하지 않는 잔여 이미지 파일은 주기적으로 자동 삭제됩니다. 저장된 위시의 이미지는 삭제 대상이 아닙니다.
  • 데이터 삭제를 원하시면 아래 연락처로 요청하실 수 있습니다.
